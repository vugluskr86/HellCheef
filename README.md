# Hell Chef — прототип

Кулинарный рогалик про повара в аду. TypeScript + WebGL2, пиксель-арт генерируется в рантайме
(ни одного внешнего ассета), пошаговый мир, permadeath с мета-прогрессией.

## Запуск

```bash
npm install
npm run build     # dist/bundle.js + dist/index.html
npm run dev       # esbuild watch + локальный сервер
npm run check     # tsc --noEmit
```

Либо просто открыть `dist/hell-chef.html` — там всё в одном файле.

Проверки:

```bash
npx esbuild tools/sim.ts    --bundle --platform=node --outfile=dist/sim.cjs    && node dist/sim.cjs
npx esbuild tools/uitest.ts --bundle --platform=node --outfile=dist/uitest.cjs && node dist/uitest.cjs
```

`sim.cjs` — балансовый прогон (дедлайны, 200 дней рынка, разброс цен, темп прогрессии, автоповар на
трое суток). `uitest.cjs` — сборка всех панелей интерфейса без браузера.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | шаг (в врага — атака) |
| E | взаимодействие: станция, стойка, лавка, койка, портал, сбор |
| I / C / R | сумка · герой · книга рецептов |
| Пробел | ждать ход |
| F5 | сохранить |

У станции: Q/E — жар, F — перевернуть, S — специя, Пробел — ждать, Enter — подавать, Esc — бросить.

## Петля

1. На кухне приходят заказы (рейка чеков справа обугливается к дедлайну).
2. Не хватает продуктов — лавка (цены ходят за спросом) или спуск в кладовые: сбор, враги, лава.
3. Готовка — пошаговая мини-игра у станции: держать температуру в зелёной зоне, вовремя переворачивать,
   попасть специями в целевой вкусовой профиль.
4. Выдача у стойки: оплата, чаевые, репутация фракции, карма.
5. Контракт круга (`2 + круг` заказов нужного качества) открывает врата в следующий круг.
6. Смерть окончательна: остаются рецепты, 30% навыков и души.

## Что реализовано

Персонаж (6 характеристик, 7 навыков с затуханием роста, уровни) · инвентарь с весом и порчей продуктов ·
20 ингредиентов с шестью вкусовыми осями · 14 рецептов, 5 станций, износ, ремонт и апгрейд ·
заказы с дедлайнами, требованиями к качеству и отказом · 6 архетипов клиентов, 6 фракций репутации, карма ·
рынок с возвратом к среднему, налог адской администрации · пошаговый бой, 4 модели ИИ, статусы
(ожог, яд, оглушение, ослепление, кровотечение), 6 инструментов-оружий · процедурные кладовые
(клеточный автомат), лава как опасность и источник света · открытие рецептов, permadeath, мета-прогрессия ·
сохранение с CRC32 и деградацией в память, если localStorage недоступен.

## Архитектура

```
src/
  core.ts      RNG, время (1 ход = 1 минута), хранилище, CRC32
  types.ts     контракты данных
  data.ts      контент: ингредиенты, рецепты, клиенты, враги, инструменты
  world.ts     хаб-кухня и генерация пещер
  cooking.ts   сессия готовки и формула качества
  orders.ts    дедлайны, выдача, провалы
  economy.ts   рынок и ценообразование
  combat.ts    бой, ИИ, статусы
  progress.ts  опыт, навыки, репутация, карма, мета
  game.ts      состояние, ход, взаимодействия, сейвы
  atlas.ts     генерация спрайтов 16×16 в canvas
  gl.ts        WebGL2-батчер
  render.ts    камера, карта света, огонь
  ui.ts        DOM-интерфейс поверх канваса
```

Логика не знает про DOM и WebGL — поэтому `tools/sim.ts` гоняет её в node целиком.

Разбор нестыковок исходного ТЗ — в [BALANCE.md](BALANCE.md).
